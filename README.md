# Рубежный контроль № 1 по дисциплине «Парадигмы и конструкции языков программирования»

**Вариант запросов:** Г  
**Предметная область:** № 1 — «Студент — Группа»

## Запуск

Требуется Python 3. Запустите программу из этой папки:

```bash
python3 main.py
```

Автоматические тесты запускаются командой:

```bash
python3 -m unittest -v
```

Программа использует только стандартную библиотеку Python.

## Структура программы

- `Student` описывает студента: идентификатор, фамилию, размер стипендии в рублях и ID основной группы.
- `Group` описывает учебную группу: идентификатор и название.
- `StudentGroup` хранит пары ID студента и группы для связи многие-ко-многим.
- Списки `students`, `groups` и `student_groups` содержат тестовые данные.

Связь **один-ко-многим** задаётся полем `group_id` студента: у студента одна основная группа, у группы может быть несколько студентов. Связь **многие-ко-многим** задаётся отдельным списком `student_groups`: студент может состоять в нескольких группах.

## Запросы варианта Г

- **Г1:** группы, название которых начинается с русской буквы «А», и фамилии студентов, состоящих в этих группах.
- **Г2:** максимальная стипендия в каждой непустой основной группе; результат отсортирован по убыванию стипендии.
- **Г3:** все пары связанных студентов и групп, отсортированные по названию группы.
